## 加密通话的原理：你的声音是如何被保护起来的？

在对比具体软件之前，先简单讲一下加密通话的技术原理，这样你后面看表格的时候会更有概念。

加密通话的核心是**端到端加密（End-to-End Encryption, E2EE）**。当你对着手机说话时，你的手机会在本地把语音数据加密成一串乱码，然后通过网络传输到对方的手机上再解密播放。中间经过的任何服务器、路由器、基站，看到的都只是加密后的数据，无法还原你的通话内容。

目前业界最广泛使用的加密协议是 **Signal Protocol**，它由 Signal 团队开发并开源，具体技术细节可以查看 [Signal Protocol 官方文档](https://signal.org/docs/security/)。这个协议的特点是使用了"双棘轮算法"（Double Ratchet Algorithm），每次通话都会生成新的密钥，即使某一次的密钥被破解，也不会影响之前和之后的通话安全。

需要特别区分两个概念：

- **传输加密（TLS/SSL）**：数据在传输过程中加密，但服务器端可以解密。微信、钉钉等都属于这一类。
- **端到端加密**：只有通话双方的设备能加解密，服务器也无法读取内容。Signal、Session 等属于这一类。

这两者的安全差距是本质性的。如果你对隐私有较高的要求，一定要选择支持端到端加密的方案。

## 通话质量实测体验

参数表格看着清楚，但实际体验才是最重要的。我花了大概两周时间，用这 8 款软件分别和不同的人做了语音和视频通话测试。测试环境包括：家庭 Wi-Fi、4G/5G 移动网络、以及通过代理节点的网络环境。

### Signal：通话质量的标杆

Signal 的语音通话质量是我体验过最好的之一。它使用 Opus 编解码器，这玩意儿在网络条件不好的时候也能自适应降低码率来保持通话连续性。我在地铁里用 4G 打 Signal 电话，虽然偶尔有零点几秒的卡顿，但整体体验比微信语音通话还要稳定。

视频通话支持最高 720p，画质清晰度够用但不算惊艳。群组视频通话最多支持 8 人同时在线，画面会自动切换到正在说话的人。

唯一的问题是网络延迟。因为需要走代理，延迟通常在 200-500ms 之间，偶尔会感觉到明显的"回声"效应。如果你和对方都有稳定的代理节点，这个问题会好很多。

### 蝙蝠聊天：国内用户的务实之选

蝙蝠聊天的语音通话质量中规中矩，在 Wi-Fi 环境下表现不错，但在弱网环境下会有比较明显的延迟和音质下降。不支持群组通话是一个硬伤，如果你经常需要多人的语音会议，蝙蝠可能不够用。

最大的优势就是不用翻墙，在国内网络环境下直接使用。注册也不需要手机号，用一串随机 ID 就可以，这点在隐私保护上做得不错。

### Session：匿名与质量的平衡

Session 的通话质量接近 Signal，毕竟底层也是基于 Signal Protocol。它通过洋葱路由（类似 Tor 的机制）来隐藏 IP 地址，这导致延迟比 Signal 还要高一些，通常在 300-600ms 之间。

如果你追求极致的匿名性，Session 是最好的选择之一——不需要手机号、不需要邮箱、甚至不需要用户名。但如果你在意通话的流畅度，可能需要在匿名性和体验之间做个取舍。

### Telegram：稳定但加密要手动确认

Telegram 的通话质量在代理环境下表现很好，可能是因为它在全球部署了大量的服务器节点。语音清晰，视频流畅，体验接近原生电话。

但要注意一个重要细节：Telegram 的普通通话默认**不是端到端加密的**。你需要在通话界面上看到那个锁头图标，才说明开启了"私密通话"模式。而且对方也需要同时确认，才能建立 E2EE 连接。这个设计虽然保证了安全性，但使用门槛确实有点高。

### Threema：贵但靠谱

Threema 的通话质量不错，延迟控制得比较好（它有亚洲节点）。加密使用的是 NaCl 库而非 Signal Protocol，但同样经过了第三方安全审计。收费模式（一次性买断约 60 元人民币）劝退了不少人，但从安全角度来说，它的加密实现是经过充分验证的。

### Wire 和 WhatsApp：成熟但各有顾虑

Wire 的通话质量很稳定，群组通话体验好，但母公司经历过安全相关的争议。WhatsApp 通话质量优秀，用户基数大，但 Meta 的隐私政策让人不安——虽然通话内容是端到端加密的，但元数据（谁和谁打了多久电话）仍然会被收集。

### SimpleX：理念先进，通话功能待完善

SimpleX 是一个非常有理念的项目——它不使用任何用户标识符，连服务器都不知道你在和谁通讯。但目前只支持语音消息，不支持实时语音通话。如果你主要是发消息为主、偶尔需要语音沟通，SimpleX 值得尝试；如果经常需要打电话，暂时还不太实用。

## 不同场景下的加密通话方案推荐

根据我自己这几年的使用经验，不同需求的人群适合不同的方案。

### 日常通用：Signal

如果你只能选一款，选 Signal。加密最强、通话质量好、功能完善、完全开源且免费。唯一的门槛是需要翻墙，如果你有稳定的网络环境，Signal 是没有争议的第一选择。

### 国内直连：蝙蝠聊天 / Threema

如果你不想折腾翻墙，[国内无需翻墙的加密通讯方案](/scenarios/no-vpn/)里有详细的分析。简单来说：蝙蝠聊天免费好用但闭源，Threema 付费但经过审计。预算允许的话我更推荐 Threema。

### 极致匿名：Session / SimpleX

如果你有特殊的安全需求，比如记者采访爆料人、律师和当事人沟通，Session 和 SimpleX 是最合适的选择。它们都不需要手机号注册，Session 还通过洋葱路由隐藏了你的 IP 地址。不过通话延迟会高一些，这是为匿名性付出的代价。

### 混合方案：实际使用中的策略

我自己的实际做法是：日常工作用 Signal，国内联系人不方便翻墙的就用蝙蝠聊天传递一些敏感信息，极端情况下用 Session。没必要强迫所有人都用同一个软件——根据对方的网络条件和技术接受度灵活选择，才是最务实的策略。

## 总结

选择加密通话软件，本质上是在**安全性**、**易用性**和**可及性**之间做平衡。没有一款软件在所有维度都是完美的，但了解它们的优劣势之后，你完全可以组合出一套适合自己的通讯方案。

最后再强调几个容易被忽略的要点：

1. **加密只保护传输过程**。如果手机本身被植入间谍软件，或者通话环境本身就不安全（比如旁边有人），再强的加密也没用。
2. **对方也需要用同样的软件**。加密通话是双向的，你用 Signal 对方也得装 Signal。
3. **定期更新软件**。安全漏洞随时可能被发现，保持软件最新版本是最基本的安全习惯。
4. **元数据也有隐私价值**。即使通话内容加密了，"谁在什么时间打了多久的电话"这些元数据同样可能泄露信息。
